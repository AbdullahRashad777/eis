# Emerald International School (EIS) — Smart Behavioral & Academic Portal

Unified Management, 9-Period Sun–Thu Timetable, Auto-Substitution Engine, Teacher Learning Hub, Student/Parent Behavioral Portals, and Psychological Performance Engine (Zeigarnik Effect, Hook Model, Emerald Gems Economy).

## Quick Start
1. **Instant Browser Run**: Double-click `index.html` (or `eis_school_portal.html`) to open directly in any browser.
2. **GitHub Pages Deployment**: Upload this folder to a new GitHub repository. The included `.github/workflows/deploy.yml` automatically publishes your live portal on GitHub Pages.
3. **Database & Backend**: Import `database/schema.sql` into Supabase or PostgreSQL, or run `npm install && npm start` to start the Express API server (`backend/server.js`).
